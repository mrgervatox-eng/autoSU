This was a mini dashboard website application developed together with 3 other teammates on claude code
It was to provide a platform for three parties in aviation, ATC, pilot and ground, to communicate with each other more efficiently
Parties would take three tries to come to a negotiable conclusion on a delayed flight that would then be rule-checked
Simulations are played out using either preplanned scenarios or actual claude agents using claude's api

Also provides a small feature where one's device could be connected to the dashboard app in real time and shows turbulence data
